## ✨ About

**Drafthyle** is a small workshop making **3D printed miniatures, hand-painted figures, articulated creatures and custom keychains**. This repository is the source of our portfolio website, where you can walk through our work in 3D, look closer at every piece, and send an order request.

If you are searching for **3D printed miniatures**, **custom 3D printed keychains**, **spray painted toys**, **action figures** or **personalised gifts**, you are in the right place.

## 🧰 What we make

| | |
|---|---|
| 🎁 **Corporate keychains** | One keychain per teammate for project wins, onboarding and festivals. Printed with a name or logo, sealed in an envelope with Diwali wishes and a personal note of recognition. |
| 🎨 **Painted and spray painted pieces** | Spray painted toys, miniatures, articulated creatures and chains, and action figures, finished by hand. |
| 💌 **Names and gifts** | Personalised gifts for kids and couples with their names on them, for birthdays and anniversaries. |

## 🌟 Website highlights

- **Walk the workshop.** A 3D gallery corridor you move through by dragging, scrolling, swiping or using the arrow keys. Tap any frame to look closer.
- **3D lab.** An articulated figure you can rotate, pose with a slider and repaint in different colours.
- **Photo grid.** Every piece in a filterable grid (Corporate, Keychains, Articulated, Figures, Gifts), with a zoom view.
- **Order form.** Order requests are sent securely through Google Forms.
- **Made for phones.** Responsive layout, touch friendly, and respects reduced-motion settings.
- **A little anime.** Kunai cursor, falling petals, slash effects and chunky layered type.

## 🚀 Run it locally

The 3D gallery loads photos as textures, and browsers block that when you open the file by double-clicking it. Use a small local server instead:

```bash
# from the project folder
python -m http.server 8000
```

Then open **http://localhost:8000**.

## 🌐 Deploy on GitHub Pages

1. Push `index.html` and the `photos/` folder to this repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.

Use simple photo names (letters, numbers and hyphens) and keep upper and lower case consistent, since GitHub Pages treats them as different.
